Project Overview

HireMap was a comprehensive group project for CS 2340, designed to address a key inefficiency in the job-seeking market: location. While many platforms allow location-based searches, they rarely provide the visual and logistical tools to truly understand commute, talent distribution, and geographic opportunity.

HireMap is a full-stack web application built to serve three distinct user roles: Job Seekers, Recruiters, and Administrators. The primary design philosophy was to create a cohesive ecosystem where data entered by one user (like a recruiter) directly and efficiently enhances the experience for another (like a job seeker).

Core Features & Implementation Reflecting User Stories

The platform's architecture was divided by user role to ensure a focused, clutter-free experience for each.

1. The Job Seeker Experience: Empowerment and Visualization

For the job seeker, the focus was on providing powerful, intuitive tools to find the right job and manage the application process.

  • Personalized Hub: Seekers can build a comprehensive profile (US #1) and, crucially, manage granular privacy settings for what recruiters can see, ensuring user control (US #5).
  • A Dual-View Job Search: We implemented two ways to search:
    • List View: A traditional, filterable list for searching by title, skills, and visa status (US #2).
    • Map View: The platform's signature feature. We used an interactive map library (like Leaflet.js) to plot all job postings geographically (US #7).
  • Key Implementation: The Client-Side Radius Filter: To make the map truly useful, we implemented a client-side radius filter (US #8, #9). A job seeker can set their home address and use a simple slider to define a commute radius (e.g., within 15 miles). This filtering happens instantly in the browser without a page reload, providing immediate visual feedback and transforming the map from a static display into a dynamic decision-making tool.
  • Smart Tools & Integrated Tracking: The system moves beyond a simple apply button to create a full feedback loop.
    • Personalized Applications (US #3): A One-Click Apply feature that uses the seeker's profile but also provides a modal popup allowing them to attach a brief, personalized note to the recruiter.
    • Algorithmic Recommendations (US #6): A dedicated Recommended for You section on their dashboard, driven by skills listed in their profile.
    • Visual Application Tracking (US #4): A personal Kanban board where seekers can visually track their application status (Applied, In Review, Interview, Offer, etc.) as it's updated by recruiters, closing the communication loop.

2. The Recruiter Toolkit: Efficient Sourcing and Management

For the recruiter, the system is designed to be a powerful talent-sourcing and workflow-management engine.

  • Precision Job Posting: When a recruiter posts a job (US #10), they interactively pin the exact office location on a map (US #17). This single action is the source of truth that powers the entire seeker-facing map system.
  • Proactive Candidate Sourcing: Recruiters can actively search the candidate database (US #11) or let the system work for them:
    • Candidate Recommendations (US #16): A dashboard widget that proactively suggests strong-fit candidates for active jobs.
    • Saved Search Alerts (US #15): The ability to save a complex candidate search and receive email notifications when new users match the criteria.
  • Key Implementation: Visualizing the Talent Pool: Recruiters get their own map-based insights. For any job post, they can view an Applicant Cluster Map (US #18). This visualizes the geographic locations of all applicants, providing an immediate, at-a-glance understanding of the talent pool's distribution.
  • Integrated Hiring Pipeline & Comms Hub: This is where recruiters manage the entire hiring workflow.
    • Visual Workflow (US #12): A drag-and-drop Kanban pipeline to move candidates between stages (New, Screen, Interview). This directly updates the status on the seeker's personal board (US #4).
    • Team Collaboration (US #13): The ability to add private, internal-only notes to a candidate's profile for team evaluation, which are not visible to the applicant.
    • Integrated Communication: The system manages key communication touchpoints. Recruiters can schedule interviews directly from the pipeline, which sends an invitation to the candidate (US #14), and they receive the seeker's personalized application note (US #3) directly in the applicant view.

3. The Administrator Backbone: Platform Health and Integrity

To ensure the platform remains stable, secure, and functional, the admin panel provides essential oversight.

  • Platform Governance: Admins have full control over the system's health, including:
    • User Management: Assigning roles (Seeker, Recruiter, Admin) and managing user accounts (US #19).
    • Content Moderation: A queue for reviewing and approving job posts to maintain platform quality (US #20).
  • Data & Analytics: An export feature allows admins to download CSV reports for users, jobs, and applications, providing crucial data for business analysis and reporting (US #21).

Reflection: A Cohesive, Story-Driven System

This project was a valuable exercise in translating 21 distinct user stories into a single, cohesive application. The key to our success was data reusability.

The geospatial data was the connective tissue of the entire platform. A single action a recruiter pinning a location (US #17) was efficiently stored and reused to power four separate features. But this philosophy extended everywhere: a status update on the recruiter's Kanban board (US #12) immediately populated the seeker's board (US #4).

By focusing on how data from one user story could flow to and enable another, we built a complex, multi-sided system. This data-first approach ensured that every feature from the large-scale maps to the granular details of a Kanban status, a private note, or an application message felt purposeful and seamlessly integrated.
