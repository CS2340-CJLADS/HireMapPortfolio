User Stories

  1. Job Seeker Create a profile with my headline, skills, education, work experience, and links so recruiters can learn about me.
  2. Job Seeker Search for jobs with filters (title, skills, location, salary range, remote/on-site, visa sponsorship) so I can find opportunities that match my needs.
  3. Job Seeker Apply to a job with one click and include a tailored note so my application feels personalized.
  4. Job Seeker Track the status of my applications (Applied → Review → Interview → Offer → Closed) so I know where I stand.
  5. Job Seeker Set privacy options on my profile so I control what recruiters can see.
  6. Job Seeker Receive recommendations for jobs based on my skills so I discover opportunities I might have missed.
  7. Job Seeker View job postings on an interactive map so I can see which ones are near me.
  8. Job Seeker Filter jobs on the map by distance from my current location so I can prioritize nearby opportunities.
  9. Job Seeker Set a preferred commute radius (e.g., 10 miles) on the map so I only see jobs within a reasonable travel distance.
  10. Recruiter Post and edit job roles so candidates can apply to my openings.
  11. Recruiter Search for candidates by skills, location, and projects so I can find talent that fits my positions.
  12. Recruiter Organize applicants in a pipeline (e.g., a Kanban board) so I can easily manage hiring stages.
  13. Recruiter Add internal notes to candidate profiles so I can record evaluation details.
  14. Recruiter Schedule interview slots for candidates so the hiring process is organized.
  15. Recruiter Save a candidate search and get notified about new matches so I don't have to repeat the same queries.
  16. Recruiter Receive candidate recommendations for my job postings so I find qualified applicants faster.
  17. Recruiter Pin my job posting's office location on a map so candidates know exactly where the job is based.
  18. Recruiter See clusters of applicants by location on a map so I understand where most candidates are coming from.
  19. Administrator Manage users and roles so the platform remains fair and safe.
  20. Administrator Moderate or remove job posts so the platform stays free of spam or abuse.
  21. Administrator Export data (CSV) for reporting purposes so stakeholders can analyze usage.
